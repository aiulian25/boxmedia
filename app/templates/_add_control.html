{# The Add control, in one place. Every page that offers to add a film includes this — the weekly card, a search result, the movie modal — so a multi-instance setup gets the same caret naming each Radarr wherever it is offered, and there is one form to audit. Quality and folder are never asked per title: each connection carries its own, set once in Settings. `target` names WHICH connection and is the only thing the browser chooses; `add_movie` refuses an id that is not in apps.yml. One connection: a plain button. Several: the caret names them, so you pick a box rather than a quality. Expects `tmdb_id`, `title`, `year` and `report_id` bound by the caller; `targets`, `show_targets`, `csrf_token` and `url_base` come from the page context. `report_id` is where the add returns to — blank means the film has no report context (the modal opened from the dashboard, say), and `add_movie` sends those back to the film's own page. #}
